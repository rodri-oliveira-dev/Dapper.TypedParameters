# Documentation Decisions

## D01 - Stable 1.0 Public Documentation

- Canonical language: English.
- Maintained translation: Português (Brasil).
- Current stable package: `TypedParameters.Dapper.SqlServer` `1.0.0`.
- Primary installation command:
  `dotnet add package TypedParameters.Dapper.SqlServer`.
- Historical prereleases are not promoted in primary documentation.
- README role: public landing page and quick-start entry point.
- docs role: detailed usage and conceptual documentation.
- Performance claims: no universal performance guarantees.
- Schema inspection: not supported.
- Automatic SQL type selection: not supported.
- NuGet identity is distinct from assembly and namespace identity.
- Public docs describe the product state, not the internal release process.
